# 📝 考试日历 · 报名 考试 成绩一览

> 考研、国考、四六级、教资、会计、注会、法考、软考、一建等 20 门全国统一考试的报名、考试、出成绩时间，带截止倒计时，可以一键加到手机日历

**🌐 在线访问：[https://climb0516.github.io/exam-calendar/](https://climb0516.github.io/exam-calendar/)**

---

## 功能

- **概览**：正在报名的考试（截止倒计时 + 进度条 + 报名入口）、下一场考试、下一次出成绩、下一个开始报名；接下来 45 天的日程；官网近 7 天的新公告
- **时间线**：按月份排列所有报名、准考证、考试、成绩节点，可显示已过去的
- **考试一览**：按类别（升学、公务员、语言、计算机、教师、财会、法律、职业资格）列出每门考试各场次的日程，附官网最新公告和报名入口
- **最新公告**：各考试官网的公告每天抓取，近 7 天新出现的标「新」；国考、注会、法考的官网抓不到，用新闻补充
- **我关注的考试**：点选标星，可以只看关注的（保存在本机浏览器）
- **加到手机日历**：下载 `.ics` 文件（关注的考试；没关注就是全部），导入 iPhone / 安卓日历；报名截止前一天、考试前一天会提醒
- 全文搜索（`⌘K` / `Ctrl K`），深浅色切换，手机适配

## 数据

| 文件 | 内容 | 更新方式 |
|---|---|---|
| `exams.json` | 各考试各场次的报名、考试、成绩日期；每个日期标 `official`（附官方来源链接）或 `estimate`（官方还没公布，按往年惯例推算，页面标「预估」） | **人工维护**，各考试发布报名公告、人社部发布年度计划时更新 |
| `data.json` | 官网最新公告 | `scraper.py` 每天自动抓取 |

公告来源：研招网、四六级 / 教资 / 计算机等级官网（教育部教育考试院）、中国人事考试网、会计资格评价网、软考官网；国考、注册会计师、法考用 Google / Bing 新闻。

**注意**：教资、会计、软考、职业资格等按省报名的考试，各省时间不同，`exams.json` 里写的是全国大致区间，以本省公告为准。

### 更新 exams.json

每门考试的结构：

```
{
  "id": "kaoyan", "name": "全国硕士研究生招生考试", "short": "考研", "category": "升学",
  "site": "https://yz.chsi.com.cn/", "keywords": "研考|硕士研究生",
  "sessions": [
    { "label": "2027 年度", "events": [
      { "type": "报名", "start": "2026-10-15", "end": "2026-10-24", "status": "official", "source": "https://...", "note": "" }
    ] }
  ]
}
```

- `type`：预报名、报名、确认、准考证、考试、成绩
- `keywords`：官网公告标题命中就挂到这门考试下（正则）
- 官网出现新公告（页面标「新」）时，打开公告核对日期，把对应的 `estimate` 改成 `official` 并填 `source`

## 技术架构

```
GitHub Actions（每天北京时间 08:30 / 手动 / 修改爬虫后 push）
  ↓ python scraper.py（只用标准库，无需安装依赖）
  ↓ 并发抓取 7 个官网 + 3 组新闻 → 与上一份 data.json 合并（记录首次出现日期，保留 120 天）
  ↓ 写入 data.json 并 commit
       ↓
GitHub Pages（index.html）
  ↓ 前端读取 exams.json + data.json 渲染，倒计时、.ics 文件都在浏览器里生成
```

- 某个来源本次抓取失败时沿用上一次的数据，右侧「公告来源」标注「旧数据」
- 每次运行都会产生提交，仓库保持活跃，定时任务不会因 60 天无活动被 GitHub 停用

本地预览：

```
python3 scraper.py
python3 -m http.server
```
